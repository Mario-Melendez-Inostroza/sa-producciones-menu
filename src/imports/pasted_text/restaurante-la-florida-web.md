Quiero crear un prototipo de alta fidelidad, moderno y profesional para un negocio gastronómico de La Florida, Santiago de Chile.

Adjunto dos imágenes de referencia:
1. Un flyer real del menú diario de colaciones.
2. Una captura del Instagram del negocio, donde se puede apreciar su logo, identidad visual y los servicios de banquetería que ofrecen.

UTILIZA LAS IMÁGENES ADJUNTAS COMO REFERENCIA VISUAL REAL DEL NEGOCIO.
No reemplaces su identidad por una marca genérica. Respeta especialmente el estilo del logo, colores, personalidad y tipo de fotografía que aparece en las referencias.

========================================
OBJETIVO DEL PROTOTIPO
========================================

El negocio actualmente envía manualmente por WhatsApp el menú de cada día a diferentes grupos y clientes.

Cada día necesitan comunicar:
- Menú disponible.
- Platos del día.
- Precios.
- Opciones para servir y para llevar.
- Agregados.
- Información sobre pedidos.
- Avisos especiales.
- Días en que estarán cerrados.
- Problemas como cortes de agua o luz.
- Cambios de horario.
- Cualquier información importante para sus clientes.

Quiero diseñar una página web que centralice toda esta información.

La propuesta debe tener DOS EXPERIENCIAS:

1. PÁGINA PÚBLICA para los clientes.
2. PANEL ADMINISTRATIVO extremadamente sencillo para que el dueño pueda actualizar la información diariamente sin conocimientos técnicos.

========================================
1. PÁGINA PÚBLICA
========================================

Diseña una página web responsive, pensada principalmente para usuarios de celular, ya que muchos clientes llegarán desde WhatsApp.

La página debe sentirse como una combinación entre:
- Restaurante local.
- Menú diario.
- Servicio de comida para llevar.
- Banquetería profesional.

Debe ser visual, cercana, confiable y fácil de utilizar.

----------------------------------------
HEADER
----------------------------------------

Crear un header limpio con:

- Logo del negocio tomado como referencia de las imágenes adjuntas.
- Navegación:
  Inicio
  Menú del día
  Banquetería
  Contacto

En móvil utilizar un menú hamburguesa.

Agregar un botón destacado:
"PEDIR POR WHATSAPP"

El botón debe abrir conceptualmente una conversación de WhatsApp.

----------------------------------------
AVISO IMPORTANTE
----------------------------------------

Una de las características principales debe ser un sistema de aviso destacado.

Por ejemplo:

"⚠️ AVISO IMPORTANTE"

"Hoy martes 8 de septiembre atendemos con normalidad."

O alternativamente:

"⚠️ HOY ESTAREMOS CERRADOS"

"Debido a un corte de agua en el sector, no tendremos atención durante el día. Retomamos nuestras actividades mañana."

Este aviso debe aparecer en una zona muy visible de la página.

Diseñar el componente para que pueda cambiar entre:
- Información normal.
- Aviso importante.
- Negocio cerrado.

Usar una jerarquía visual clara, sin hacer que la página parezca una aplicación compleja.

3. PANEL ADMINISTRATIVO
========================================

Esta parte es MUY IMPORTANTE.

Crear una segunda vista/ruta llamada:

"Panel de administración"

La filosofía del panel debe ser:

"Que una persona que no sabe programación pueda actualizar el menú en menos de un minuto."

No diseñar un dashboard empresarial complejo.

Debe ser extremadamente simple.

========================================
EXPERIENCIA DE USUARIO
========================================

El diseño debe priorizar:

- Mobile first.
- Lectura rápida.
- Botones grandes.
- Tipografía clara.
- Precios muy visibles.
- Pocos pasos.
- WhatsApp como principal canal de contacto.
- Actualización diaria extremadamente sencilla.

No crear una interfaz tecnológica o fría.

Debe sentirse como un negocio gastronómico local, familiar y profesional.

========================================
ESTILO VISUAL
========================================

Utilizar las imágenes adjuntas como referencia principal de identidad.

Conservar la personalidad visual del negocio y del material existente, pero modernizar la presentación.

La interfaz debe combinar:

- Colores inspirados en el logo y flyer.
- Rojo como color de énfasis cuando corresponda.
- Tonos cálidos y gastronómicos.
- Fondos claros.
- Mucho espacio en blanco.
- Fotografías grandes.
- Bordes ligeramente redondeados.
- Sombras suaves.
- Tipografía gruesa y amigable para títulos.
- Excelente legibilidad en celulares.

No hacer un diseño corporativo genérico.

Debe parecer una marca gastronómica chilena cercana, moderna y confiable.

========================================
PROTOTIPO INTERACTIVO
========================================

Crear las principales interacciones:

1. "Ver menú de hoy" hace scroll al menú.
2. "Pedir por WhatsApp" abre conceptualmente WhatsApp.
3. "Quiero cotizar mi evento" dirige al contacto/WhatsApp.
4. El menú hamburguesa funciona en móvil.
5. El administrador puede entrar al panel.
6. "Editar menú" muestra el formulario.
7. "Agregar plato" crea una nueva tarjeta.
8. "Guardar cambios" actualiza la vista previa.
9. "Publicar aviso" cambia el aviso visible en la página pública.
10. "Estamos cerrados" muestra claramente el estado de cierre en la página pública.
11. "Usar este menú como base" permite reutilizar un menú anterior.
