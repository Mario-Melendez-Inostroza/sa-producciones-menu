# Contexto — S&A Producciones

## Resumen
Sitio web de S&A Producciones: colaciones caseras y banquetería en La Florida, Santiago.
Sitio en vivo: https://sa-producciones-menu.vercel.app/

## Objetivo del sitio
Mostrar el menú del día y la banquetería, y facilitar el contacto.

## Público
Personas y empresas de La Florida que piden colaciones diarias o banquetería para eventos.

## Secciones
- Menú del día
- Banquetería para eventos
- Contacto

## Contenido y datos
- Los textos, precios, teléfonos y certificaciones los entrega el cliente. La IA no inventa información del negocio: si falta un dato, se deja marcado como "por confirmar".
- El menú del día y los avisos son contenido que cambia con frecuencia: actualizarlos sin alterar el diseño.

## Restricciones
- Este repositorio contiene solo el frontend (sin backend propio).
- No se suben secretos ni datos personales. Las variables de entorno van en .env (no versionado) y solo se usan variables públicas VITE_*.
- El dominio y el despliegue los gestiona una persona, no la IA.
