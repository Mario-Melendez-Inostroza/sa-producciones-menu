# S&A Producciones — Colaciones y Banquetería

Sitio web de **S&A Producciones**, servicio de colaciones caseras y banquetería en La Florida, Santiago.

**Sitio en vivo:** https://sa-producciones-menu.vercel.app/

## Secciones

- Menú del día
- Banquetería para eventos
- Contacto

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Despliegue en Vercel

## Cómo ejecutarlo

```bash
npm install
npm run dev      # servidor de desarrollo
npm run build    # build de producción
```
